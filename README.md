# HomeFlix Cyber Node

HomeFlix is a simple, local-first media player that runs in your browser. Choose media files from your device, open a folder, or drag and drop files into the page.

## Features

- Play local video and audio files.
- View images and animated GIFs.
- Select multiple files or choose a folder.
- Drag and drop media into the player.
- Search, sort, filter, and favorite items during the current session.
- Responsive dark interface with playback controls.

## Privacy

HomeFlix does not upload, store, or publish your media. Files are read locally by your browser and are not sent to a server. Your library is a temporary browser session; re-add files after refreshing or reopening the page.

## Deploy on Vercel

This is a static website. Import this repository into Vercel and deploy it with no environment variables, upload tokens, or server-side media API required.

## Supported formats

Playback depends on the codecs supported by your browser. Some formats, including certain MKV, AVI, HEIC, and audio codecs, may not play in every browser.
